# Growcus Design System Guidelines

A premium matte dark theme optimized for student intelligence and analytical SaaS dashboards.

- **Color Palette**: Dark matte backgrounds (`#09090b`) with contrasting white-gray text (`#f4f4f5`), deep electric blue (`#3b82f6`) for main actions, and soft purple (`#a855f7`) for AI assistance and branding highlights.
- **Components & Layout**: Spacing should feel open yet dense with data. Elements should float above the dark base with subtle, low-opacity borders (`#27272a`). Avoid strong, stark boundaries.
- **Visual Feel**: Linear/Stripe-like dashboard style. Dark aesthetics, subtle gradients (e.g., from indigo to purple to cyan), clear status states (success, warning, error), high typographic breathing room.
